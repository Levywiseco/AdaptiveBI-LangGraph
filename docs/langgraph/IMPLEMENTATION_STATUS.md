## A包：安全与正确性修复（2026-09-25）

- **行级权限编译期注入**：指标执行链路此前只检查列可见性，未套用旧引擎的行权限，受限用户可拿到全表汇总。现在编译器对非管理员调用同一个 `get_row_permission_filters`，把规则解析后绑定到指标表并 AND 进 SQL；规则无法安全应用时 403 拒绝执行。SQL 指纹随之覆盖权限条件。
- **规划提示词统一且带日期**：唯一副本移至 `backend/apps/graph_gateway/prompts.py`，补充当前日期/时区、左闭右开时间规则与示例，修复"8月"被给成 `end=08-31` 而漏算最后一天的问题；删除图服务中未被使用且不一致的 `planning_prompt`。
- **灰度门控与授权对齐**：路由前执行与图运行相同的 `authorize_current`；嵌入式助手、非流式调用不再被路由；会话必须属于当前工作空间；白名单解析允许空格，格式错误 fail closed。

- **测试**：新增行权限单元测试（方言、失败即拒绝）和端到端测试（真实编译器与 `exec_sql` 在隔离 SQLite 上执行，只替换 PG 专用的规则查询；关闭注入后该测试失败，已验证），另加截止时间、提示词、门控和标题测试。跨环境 schema 对比测试此前只认 Windows 路径，现在 Mac/Linux 也会执行。
