**当前状态：已复制现有代码并完成迁移设计，尚未实现新的 LangGraph 编排服务。**

- [完整迁移方案与架构图](docs/langgraph/MIGRATION_PLAN.md)

运行中的原项目不会因本仓库的设计或提交自动切换引擎。
